# 轴伤部分计分与覆盖率待验证事项

状态：开发态源码允许已量化部分和明确机制估算参与装备推荐，覆盖率不足 100% 不再整体阻止搜索；发行组件尚未晋升。
已实现的计分与保存口径以[计算结果后处理](../features.md#计算结果后处理)为唯一行为说明。

## 仍存在的证据与模型缺口

- 赛季受益角色或时段缺证时，受影响逐击可不进入本次计分集合；原战报伤害保留，不能声称其换装收益为零。
- 黑羽窗口可由同目标、半场、正式黯星结算、有效时长和累计回调重建。此类窗口的倍率可作明确标记的估算，不再因为 `blackbird_window_partial` 一律阻止推荐。窗口精确成员和上限假设仍不升级为服务端事实。
- 安魂曲相关生命上限结算可按可用来源逐击的伤害加权比例估算；来源有成对公式但尚缺部分增益证据时，也可仅用该公式比例作为估算，原量化缺口保留。无可用比例的来源不以倍率一混入；完全没有可用来源时仍未计入。
- 当本次计分范围只包含不变的队友伤害时，覆盖率可能大于零而目标角色仍没有可优化收益。展示须保留“已证实不变”的含义，不能把覆盖率称为推荐准确率。

## 后续验证

继续用真实战报副本验证较长轴的推荐、覆盖率、候选计分集合不变与保存读回；数据库原始事实不得修改。
校验固定队友联动、跨半场隔离、候选丢失已计分事件、首扫预算不足、覆盖率桶守恒和部分目标提升文案。
已量化、估算与未计入的占比分开保留；不以无关模型缺项否决已可用部分，也不把估算包装成完整精确收益。
