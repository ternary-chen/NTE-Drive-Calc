# ReShade 与 RenoDX 神经渲染验证

## 当前交付与目标

目标是在《异环》使用第三方 DLSS 神经渲染，并保持 Calc 同步、战报和 HUD 正常。
工具页已提供待实测的实验配置入口；按钮、文件所有权、事务恢复与用户步骤统一维护于
[实验工具功能](../features/dlss-neural-rendering.md)。它不等于游戏内实时开关或稳定支持声明。

本机已从官网及 RenoDX 作者发布频道准备隔离候选并冻结来源、版本与哈希；运行库 NVIDIA
签名通过检查。真实游戏效果、驱动配套与 Calc 共存均尚未验证，实机操作由用户手动执行。
本机组件、备份、预检与验证说明不随仓库或安装包发布。

## 组件获取与分发待核实项

首版提供来源入口与用户自备文件夹检测，不捆绑或镜像分发当前第三方候选。
ReShade 公共源码许可证、RenoDX 框架许可证、具体神经渲染插件二进制及 NVIDIA 运行库的
授权范围需分别核对。框架开源、下载可访问或数字签名有效，均不能替代具体文件的再分发证据。
以后授权及来源闭合时再决定随包或官方下载管理，不让此项阻塞实验配置界面。

依赖关系与作者入口依据：[ReShade](https://reshade.me/)、
[RenoDX](https://github.com/clshortfuse/renodx)、
[神经渲染消费者说明](https://github.com/NIGos/dlss5-bridge)。不默认引入 Bridge、Feeder、
多帧生成解锁或 HDR 插件，不把这些能力混称为 DLSS 5。

## 实机验收

每个结论冻结游戏版本、显卡/驱动、ReShade、神经渲染插件/运行库及本方组件哈希。
原始证据保存在本机，不将真实账号、UID、日志和游戏路径写入本文。

| 场景 | 完成条件 |
| --- | --- |
| Calc 原始基线 | 同一账号同步成功，战报可采集结算，HUD 可显示和独立关闭 |
| 加入 ReShade | Calc 宿主与插件连接、同步、战报和 HUD 与基线一致 |
| 开启神经渲染 | 初始化及持续处理有证据，固定场景开关对照可辨认，无持续黑屏、崩溃或明显闪烁 |
| 同步共存 | 新完整库存可提交，账号与来源正确，不使用旧库存冒充新同步 |
| 战报共存 | 短战斗首击输入冻结、逐击、结算和历史查看完整；失败尝试保留记录 |
| HUD 共存 | 冷却/敌人信息正常，关闭 HUD 不停止战报或神经渲染 |
| 重启与恢复 | 重启后状态一致，恢复后玩家偏好保留且 Calc 可再次使用 |

画面效果、耗时和显存变化单独记录，不承诺提帧。首先验证一套已冻结的组件组合；通过后再考虑
更多版本、官方运行时渠道和直接控制游戏内开关，不能只凭安装完成扩大兼容名单。
